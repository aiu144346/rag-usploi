# 🛡️ Dify 스타일 CS 분쟁 해결 중재자 RAG 챗봇

교안(**"Dify RAG 챗봇 강의 교안.md"**)의 아키텍처와 시나리오 C(`CS-CARE-2026`)를 바탕으로, Dify에 가입하지 않고도 동일한 RAG 파이프라인과 UI를 온전히 로컬에서 구동할 수 있도록 구현한 프로젝트입니다.

---

## 🌟 핵심 구현 특징 (Dify 기능과의 1:1 매핑)

| Dify 프레임워크 기능 | 본 프로젝트 구현 내용 |
| :--- | :--- |
| **Knowledge Base (지식 베이스)** | `data/cs_policy_manual.txt` (사내 CS 정책 매뉴얼) |
| **Chunking & Preprocessing** | 문단 분할 + Overlap 기반 의미 단위 청킹 (`rag_engine.py`) |
| **High Quality Indexing (임베딩)** | Google Gemini 최신 임베딩 모델 (`text-embedding-004`) + 로컬 ChromaDB |
| **Retrieval Settings (검색 튜닝)** | `Top-K` 슬라이더 + `Score Threshold`(유사도 하한선) 슬라이더 지원 |
| **Prompt Orchestration** | 교안 모듈 4의 페르소나, 목표, 어조, `<context>` 주입 및 환각 방지 제약식 완벽 적용 |
| **Citations & Logs** | 답변 하단에 참조한 문서명, 청크 번호, 유사도 점수(Score) 배지 및 아코디언 제공 |
| **Web App UI** | Streamlit 기반의 인터랙티브 채팅 인터페이스 + 실시간 스트리밍 답변 |

## 🚀 실행 방법

### 방법 1: `run.bat` 더블 클릭 (가장 간편한 방법)
폴더 내의 `run.bat` 파일을 더블 클릭하면 자동으로 브라우저에서 웹앱이 실행됩니다.

### 방법 2: 터미널에서 실행
```powershell
cd C:\GL-AG-PJT\RAG_USPLOI
.\.venv\Scripts\streamlit.exe run app.py
```

## 🔑 Google Gemini API 키 설정

1. [Google AI Studio](https://aistudio.google.com/)에서 무료로 API 키를 발급받습니다.
2. 실행 후 웹 브라우저 좌측 사이드바의 **"Google Gemini API Key"** 입력창에 키를 입력합니다.
   *(또는 `.env` 파일에 `GEMINI_API_KEY=내_API_키` 형태로 저장해두면 자동 로드됩니다)*

## 🧪 교안 검증용 테스트 질문 예시

웹 화면 상단의 **추천 질문 버튼**을 누르면 교안에 수록된 케이스를 즉시 검증할 수 있습니다:

1. **단순 변심 & 택 제거 환불 요청 (교안 테스트 질의)**
   > *"배송 온 옷을 뜯어서 입어봤는데 마음에 안 들어요. 태그는 가위로 잘라서 버렸는데 방금 수령했으니까 당장 전액 환불해 주고 사람 보내서 가져가세요!"*
   * **기대 결과**: 택 분리/폐기로 인한 단순 변심 환불 불가 규정 정중하고 단호하게 고지
2. **배송 파손 및 무상 교환/환불 요청**
   > *"배송 온 컵이 완전히 깨져서 도착했어요! 사진은 찍어뒀는데 환불이나 교환 가능한가요? 택배비는 누가 내나요?"*
   * **기대 결과**: 30일 이내 무상 교환/전액 환불, 반품 배송비 당사 부담, 사진 증빙 확인 안내
3. **고객 폭언 대응 지침 문의**
   > *"상담원이 고객 통화를 임의로 먼저 종료해도 되나요? 어떤 경우에 법적 대응을 하나요?"*
   * **기대 결과**: 폭언/욕설 2회 이상 지속 시 즉시 통화 종료 권리 및 법적 대응 이관 안내
4. **비지식 질의 (환각 방지 제약식 검증)**
   > *"제가 어제 주식을 샀는데 손실이 났어요. 회사에서 50%라도 보상해 주나요?"*
   * **기대 결과**: 지어내지 않고 *"당사 표준 보상 규정 외의 특수 사례로 확인됩니다. ... 24시간 이내에 별도로 상세히 안내해 드리겠습니다"* 표준 멘트 출력
